1. Introducción y Descripción General

1.1 ¿Qué es DeepMove?

DeepMove es un sistema electrónico de control y monitoreo diseñado específicamente para líneas de extrusión de caucho. Se instala en la máquina extrusora y cuenta con una pantalla táctil a color de 8 pulgadas (800×480 píxeles) que permite al operador y al supervisor interactuar con el sistema de forma sencilla, sin necesidad de conocimientos de programación ni computadoras.

El sistema fue desarrollado por Rubber SRL para sus propias líneas de producción, con el objetivo de mejorar la trazabilidad, reducir el desperdicio de material y facilitar el control del proceso de extrusión.

[ Insertar foto de la pantalla táctil montada en la extrusora ]

1.2 ¿Para qué sirve?

DeepMove cumple las siguientes funciones principales:

  • Medir la velocidad de extrusión en tiempo real (metros por minuto), mostrándola en un velocímetro visual en pantalla.
  • Contar la producción: registra cuántos metros se han extruido y cuántas piezas se han cortado durante cada turno.
  • Controlar el corte automático: acciona el relé de la cortadora en el momento exacto para que cada pieza tenga la longitud correcta según el perfil seleccionado.
  • Emitir alertas sonoras y visuales cuando la velocidad se desvía del valor esperado o cuando se acerca el momento del próximo corte.
  • Guardar registros históricos de cada producción en una tarjeta de memoria (SD), con fecha, hora, perfil, metros extruidos y velocidad promedio.
  • Gestionar perfiles de extrusión: almacena las fichas técnicas de cada perfil (tipo de matriz, longitudes de corte, densidad del material, etc.) para que el operador solo tenga que seleccionar el perfil a producir.
  • Conectarse a la red WiFi de la planta para permitir supervisión remota desde una computadora.

2. La Pantalla y la Navegación

2.1 La pantalla táctil

La pantalla táctil funciona de manera similar a la pantalla de un teléfono inteligente: basta con tocar con el dedo sobre los botones, íconos o campos que aparecen en pantalla para activarlos. No se necesita ningún elemento adicional (lapicera, lápiz óptico, etc.).

La interfaz está diseñada para ser usada con guantes de trabajo finos. Se recomienda no presionar la pantalla con objetos duros o afilados para no rayarla.

Nota: Si la pantalla no responde al tacto, verificar que el dedo esté limpio y seco. Los guantes muy gruesos de goma pueden interferir con el sensor táctil.

2.2 Barra de estado superior

En la parte superior de la pantalla siempre se muestra una barra de estado con la siguiente información:

Elemento Descripción
Hora actual Muestra la hora del sistema en formato HH:MM:SS.
Estado WiFi Ícono que indica si el equipo está conectado a la red WiFi de la planta.
Estado de la SD Indica si la tarjeta de memoria está insertada y funcionando correctamente.
Indicador de estado Listo — El sistema está en espera, sin producción activa.
Grabando — Hay una producción en curso registrándose.
Alarma — Se detectó una condición anormal (ver Capítulo 7).

En la parte inferior de la pantalla hay cuatro pestañas que permiten navegar entre las secciones principales del sistema:

3.2 Cómo iniciar una producción

Seguir estos pasos en orden:

  1. Seleccionar el perfil: Ir a la pestaña Perfil, buscar y seleccionar el perfil de caucho que se va a producir. Volver a la pestaña Extruir. El nombre del perfil debe aparecer en la sección de "Perfil activo".
  2. Ajustar la cantidad de piezas: Usar los botones + y – para ingresar cuántas piezas se van a producir en este lote.
  3. Seleccionar la longitud de corte: Tocar el selector de longitud y elegir una de las longitudes predefinidas del perfil, o ingresar una medida personalizada.
  4. Presionar START: Tocar el botón de inicio (generalmente de color verde). El indicador de estado cambiará a Grabando y el sistema comenzará a registrar la producción.
Consejo: Asegurarse de que la extrusora esté funcionando y el material ya esté fluyendo antes de presionar START, para que las métricas registradas sean precisas desde el primer momento.
[ Insertar captura de pantalla mostrando el botón START activo y el estado "Grabando" ]

3.3 Durante la producción

Mientras la producción está en curso:

  • El velocímetro se actualiza en tiempo real con la velocidad actual de la extrusora.
  • Los metros extruidos aumentan continuamente.
  • El sistema acciona automáticamente el relé de corte cada vez que se alcanza la longitud de corte programada.
  • Si se configuró la alarma de antelación, el buzzer emitirá un pitido corto algunos segundos antes de cada corte para alertar al operador.
  • Si la velocidad se aleja del rango esperado, se activará la alarma de velocidad (ver Capítulo 7).
  • Cuando se completan todas las piezas del lote, el sistema detiene automáticamente la grabación y genera el registro del turno.

3.4 Cómo detener la producción

Para detener la producción antes de completar el lote, presionar el botón STOP. El sistema guardará el registro con los datos producidos hasta ese momento, indicando que la producción fue detenida manualmente.

Importante: Al detener la producción, el relé de corte también se desactiva. Verificar que la cortadora se haya detenido correctamente antes de manipular el material.

4. Pantalla "Perfil" – Selección de Perfiles

4.1 ¿Qué es un perfil?

Un perfil es la ficha técnica de cada tipo de caucho que se produce. Cada perfil contiene toda la información necesaria para que el sistema controle correctamente la producción de ese tipo específico de goma: longitudes de corte, velocidad esperada, tipo de matriz, cantidad de bocas de salida, densidad del material, etc.

Los perfiles son cargados en el sistema por el área técnica. El supervisor o el operador solo necesita seleccionar el perfil correcto antes de comenzar a producir.

4.2 Cómo buscar y seleccionar un perfil

  1. Tocar la pestaña Perfil en el menú inferior.
  2. Aparecerá una lista con todos los perfiles disponibles.
  3. Para buscar un perfil, escribir parte del código o nombre comercial en el campo de búsqueda. La lista se filtra automáticamente.
  4. Tocar el perfil deseado en la lista para ver su información completa.
  5. Confirmar la selección tocando el botón Seleccionar.

5. Pantalla "Históricos" – Registros de Producción

5.1 ¿Qué son los históricos?

Los históricos son los registros guardados automáticamente por el sistema al finalizar cada producción. Funcionan como un libro de guardia digital: cada vez que se detiene una grabación (ya sea porque se completó el lote o porque el operador la detuvo manualmente), el sistema genera un registro en la tarjeta SD con todos los datos de esa producción.

Estos registros quedan guardados indefinidamente en la tarjeta SD y pueden consultarse en cualquier momento desde esta pantalla.

Importante: Si se retira la tarjeta SD del equipo mientras está encendido, o si la tarjeta se llena, el sistema seguirá funcionando pero no guardará nuevos registros. El ícono de SD en la barra de estado indicará si hay algún problema.

5.2 Cómo navegar los registros

  1. Tocar la pestaña Históricos en el menú inferior.
  2. Aparecerá un explorador de archivos organizado por carpetas por fecha.
  3. Tocar una carpeta para ver los registros de ese período.
  4. Tocar un archivo para ver su contenido directamente en la pantalla.

5.3 Datos registrados por turno

Cada registro de producción contiene la siguiente información:

Dato Descripción
Fecha y hora de inicio Momento exacto en que se presionó START.
Fecha y hora de fin Momento exacto en que se detuvo la producción.
Perfil utilizado Código del perfil de caucho producido.
Total de metros extruidos Metros totales de perfil producidos durante esa sesión.

Consejo para supervisores: Revisar los históricos al inicio del turno permite comparar la producción real del turno anterior con la planificada y detectar desvíos de velocidad o bajo rendimiento.

6.1 Fecha y Hora

Permite ajustar la fecha y hora del sistema. Es importante que el reloj esté correctamente configurado, ya que todos los registros históricos se guardan con marca de tiempo.

Procedimiento para ajustar la fecha y hora:

  1. Tocar la pestaña Fecha/Hora dentro de Configuración.
  2. Usar los rodillos deslizables (similar a una rueda) para ajustar cada valor: horas, minutos, segundos, día, mes, año.
  3. Deslizar hacia arriba o hacia abajo sobre cada rodillo para cambiar el valor.
  4. Confirmar tocando el botón Guardar.
Nota: El sistema cuenta con un reloj interno con batería propia (RTC) que mantiene la hora aunque el equipo esté apagado. Solo es necesario ajustar la hora si se cambió la batería del RTC o si el equipo estuvo desconectado por un período prolongado.

6.2 WiFi

Permite conectar el sistema a la red WiFi de la planta para habilitar el acceso remoto por web (ver Capítulo 10).

Procedimiento para conectar a WiFi:

  1. Tocar la pestaña WiFi dentro de Configuración.
  2. Tocar Escanear redes para ver las redes WiFi disponibles.
  3. Seleccionar el nombre de la red de la planta (SSID).
  4. Ingresar la contraseña de la red tocando el campo correspondiente.
  5. Tocar Conectar. El estado cambiará a "Conectando..." y luego mostrará la dirección IP asignada si la conexión fue exitosa.
Estado WiFi Significado
Sin credenciales No se ingresó ninguna red. El WiFi está inactivo.
Conectando... El equipo está intentando conectarse a la red.
Conectado (IP: xxx.xxx.x.xx) Conexión exitosa. Se muestra la dirección IP para el acceso remoto.
Error: contraseña incorrecta Verificar que la contraseña ingresada sea correcta.
Error: red no encontrada La red seleccionada no está al alcance del equipo. Verificar el router.

7. Alarmas y Alertas

DeepMove cuenta con un sistema de alertas que avisa al operador y al supervisor cuando ocurre alguna condición anormal o cuando se acerca un evento importante del proceso. Las alertas combinan señales visuales (cambio de color en la pantalla) y sonoras (buzzer).

7.1 Tipos de alarma

Tipo de alarma Señal sonora Señal visual Causa
Alarma de velocidad 3 pitidos de 500ms (repetido) Indicador de estado en Alarma La velocidad real se desvió del rango aceptable para el perfil seleccionado.
Aviso de corte próximo 1 pitido de 500ms Ninguna (solo sonido) Faltan N segundos para el próximo corte automático.
[ Insertar captura de pantalla mostrando el indicador de "Alarma" activo ]

7.2 Qué hacer ante una alarma

Ante una alarma de velocidad:

  1. Observar la velocidad en el velocímetro y determinar si la extrusora está yendo muy rápido o muy lento.
  2. Verificar el estado de la extrusora: temperatura del cilindro, nivel de material, presión de extrusión.
  3. Ajustar la velocidad del variador de frecuencia (VFD) de la extrusora según corresponda.
  4. Una vez que la velocidad vuelve al rango aceptable, la alarma se desactiva automáticamente.

Ante el aviso de corte próximo:

Este aviso no indica un problema: solo informa que en unos segundos se realizará el corte automático. Asegurarse de que no haya personas o materiales en la zona de la cortadora.

Consejo: Si la alarma de velocidad suena con frecuencia durante una producción, revisar los parámetros del perfil con el área técnica, ya que puede indicar que los valores de velocidad de referencia no están correctamente cargados en el perfil.

8. Calibración de Longitud

8.1 Cuándo calibrar

El sistema mide la longitud del perfil extruido mediante un sensor que cuenta las vueltas de un rodillo encoder. Con el tiempo, factores como el desgaste del rodillo, cambios en la tensión del material o la sustitución del rodillo por otro de diferente diámetro pueden hacer que la medición acumulada difiera de la longitud real.

Se recomienda realizar una calibración en los siguientes casos:

  • Cuando se reemplaza el rodillo encoder por uno de diferente diámetro.
  • Cuando se detecta una diferencia sistemática entre la longitud indicada en pantalla y la longitud medida físicamente con una cinta métrica.
  • Periódicamente (por ejemplo, una vez por mes) como parte del mantenimiento preventivo.

8.2 Procedimiento de calibración

  1. Extruir una longitud conocida de perfil (por ejemplo, exactamente 10 metros) midiendo físicamente con una cinta métrica de precisión.
  2. Anotar la longitud que el sistema mostró en pantalla para esa misma producción (longitud teórica).
  3. Ir a Configuración → Máquina → Calibración de longitud.
  4. Ingresar en el campo "Longitud teórica" el valor que indicó el sistema (ej: 10.2 m).
  5. Ingresar en el campo "Longitud real" la longitud medida físicamente (ej: 10.0 m).
  6. El sistema calculará automáticamente el factor de corrección.
  7. Tocar Aplicar para confirmar.
Límite de corrección: El sistema solo acepta factores de corrección dentro del rango ±20% respecto al valor actual. Si la diferencia es mayor, verificar que el sensor y el rodillo estén correctamente instalados, ya que podría indicar un problema mecánico.
Nota: Se recomienda hacer la calibración con una longitud de referencia grande (10 metros o más) para minimizar el error de medición con la cinta métrica.

9. Contador de Pintura (Spray)

Si la línea de extrusión cuenta con un sistema de marcado por spray (pintura en aerosol), DeepMove lleva un contador de disparos para saber cuándo reponer el cartucho o lata de pintura.

El contador se decrementa automáticamente en 1 unidad por cada corte/marcado que realiza el relé del marcador.

Configuración del contador:

Parámetro Descripción Rango
Capacidad del spray Número total de disparos que tiene el cartucho de pintura. 1 – 9999 disparos
Disparos restantes Contador que muestra cuántos disparos quedan antes de que se agote el spray. Calculado automáticamente
Botón Resetear Al reemplazar el cartucho de pintura, presionar este botón para reiniciar el contador al valor de capacidad máxima. –
Consejo: Resetear el contador cada vez que se reemplaza el cartucho de pintura. Si el contador llega a cero y no se resetea, el sistema no desactivará el relé del marcador, pero la indicación en pantalla dejará de ser confiable.

10. Acceso Remoto por Web

Cuando DeepMove está conectado a la red WiFi de la planta, es posible monitorear la producción en tiempo real desde cualquier computadora o tablet conectada a la misma red, sin necesidad de instalar ningún programa adicional.

Cómo acceder:

  1. Verificar que el equipo DeepMove esté conectado a WiFi (ver sección 6.2). Anotar la dirección IP que aparece en la pantalla de configuración WiFi (ejemplo: 192.168.1.105).
  2. Desde una computadora o tablet conectada a la misma red WiFi, abrir un navegador web (Chrome, Firefox, Edge, etc.).
  3. En la barra de dirección del navegador, escribir la dirección IP del equipo:
    http://192.168.1.105
    (reemplazar los números con la IP real del equipo).
  4. Se abrirá el panel de monitoreo web con los datos de producción en tiempo real.
Nota: La dirección IP del equipo puede cambiar si se reinicia el router. Si el acceso falla, verificar la IP actual en Configuración → WiFi en la pantalla del equipo.
Importante: El acceso web es de solo lectura: permite ver los datos de producción pero no permite controlar el equipo ni cambiar su configuración desde la computadora. El control siempre se realiza desde la pantalla táctil del equipo.

11. Mantenimiento Básico y Solución de Problemas

Mantenimiento preventivo recomendado

Frecuencia Tarea
Diario Limpiar la pantalla táctil con un paño seco o levemente húmedo (sin solventes). Verificar que el ícono de SD esté activo.
Semanal Verificar que los históricos se estén guardando correctamente abriendo los registros del día anterior.
Mensual Realizar la calibración de longitud. Verificar la hora del sistema. Revisar el nivel del contador de spray si corresponde.
Según necesidad Actualizar el firmware cuando haya una nueva versión disponible. Formatear la tarjeta SD si está muy llena (hacer respaldo antes).

Solución de problemas comunes

Problema Posible causa Solución
La pantalla no responde al tacto Contaminación en la pantalla o guantes muy gruesos. Limpiar la pantalla con un paño limpio y seco. Probar sin guantes.
El velocímetro no se mueve durante la producción El sensor inductivo no está detectando el rodillo encoder. Verificar que el sensor esté correctamente posicionado y que el rodillo encoder esté girando. Llamar al técnico si persiste.
No se guardan históricos Tarjeta SD no insertada, llena o dañada. Verificar la tarjeta SD. El ícono en la barra de estado indicará el problema.
La cortadora no se activa en el momento del corte El relé de marcado está desactivado en la configuración. Ir a Configuración → Máquina → Relé de marcado y verificar que esté en ON.
No conecta a WiFi Contraseña incorrecta, red fuera de alcance o router apagado. Verificar la contraseña y que el router esté encendido. Intentar escanear redes nuevamente.
La hora del sistema está mal Batería del RTC agotada o ajuste incorrecto. Ajustar la hora en Configuración → Fecha/Hora. Si sigue cambiando al apagar, avisar al técnico para cambiar la batería del RTC.
La actualización de firmware falla Conexión WiFi inestable o servidor no disponible. Verificar la conexión WiFi. Reintentar en otro momento. El sistema vuelve a la versión anterior automáticamente.
La longitud medida no coincide con la real El factor de calibración está desajustado. Realizar el procedimiento de calibración descripto en el Capítulo 8.

12. Glosario de Términos

Término Significado
Boca de salida Orificio de la matriz de extrusión por donde sale el perfil de caucho.
Calibración Proceso de ajuste de la medición del sensor para que coincida con la realidad.
Encoder Rodillo que gira en contacto con el perfil extruido y permite al sensor contar la longitud producida.
Firmware Software interno del equipo (como el sistema operativo de un celular). Se puede actualizar remotamente.
HMI Interfaz Hombre-Máquina (Human Machine Interface). Nombre técnico del sistema de pantalla táctil para operar la máquina.
IP / Dirección IP Número de identificación del equipo en la red WiFi, necesario para acceder al panel web (ej: 192.168.1.105).
OTA Over-The-Air. Actualización del firmware del equipo a través de la red WiFi, sin intervención presencial del técnico.
Perfil Ficha técnica de un tipo de caucho específico que contiene todos los parámetros necesarios para su producción.
Relé Componente electrónico que actúa como un interruptor controlado por el sistema. Se usa para activar la cortadora o marcadora.
RTC Reloj de Tiempo Real (Real Time Clock). Módulo electrónico que mantiene la hora del sistema aunque el equipo esté apagado.
Sensor inductivo Dispositivo que detecta objetos metálicos sin contacto. Se usa para detectar las marcas del rodillo encoder.
SD / Tarjeta SD Tarjeta de memoria removible donde se almacenan los registros históricos de producción.
VFD Variador de Frecuencia. Dispositivo que controla la velocidad del motor de la extrusora.
WiFi Red inalámbrica de área local. Permite que el equipo se comunique con otras computadoras de la planta sin cables.
